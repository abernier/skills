# AGENTS.md

`abernier/skills` — a [Claude Code plugin](https://code.claude.com/docs/en/plugins)
published as the `abernier` plugin from the `abernier-skills` marketplace.

## Agent skills

### Issue tracker

Issues live as GitHub issues in `abernier/skills`, via the `gh` CLI. External PRs are
not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary — each role's label string equals its name. See
`docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and one `docs/adr/` at the repo root. See
`docs/agents/domain.md`.
